## 支持的影像格式

RadiAnt 支持的 DICOM 图像类型相当全面：

- 数字放射摄影（CR、DX）
- 乳腺摄影（MG）
- 计算机断层扫描（CT）
- 磁共振成像（MR）
- PET-CT（PT）
- 超声检查（US）
- 数字血管造影（XA）
- 核医学（NM）
- 结构化报告（SR）

单色、彩色、静态、动态序列，压缩和非压缩格式（RLE、JPEG 有损/无损、JPEG 2000）都支持。基本上医院里遇到的影像格式，都能打开。
